# A Protected block tells only the attacker, never the target or the Bodyguard

When a Strike or knife is blocked by Protected status, only the attacker (the Killer, Vigilante, or Hitman) gets a message. The Protected Participant never learns they were saved, and the Bodyguard never learns their one-time save actually fired.

We considered giving the Bodyguard a confirmation message, since every other single-use Civilian Role item (the Vigilante's knife) gives clear feedback on its own outcome. We chose total silence toward the Bodyguard and the target instead, because the Bodyguard's entire value is secrecy - telling them "it worked" would be the only piece of information in the whole game that confirms a specific Participant isn't the Killer's next victim, and telling the target would let them deduce a Bodyguard exists and start probing for who it is. Only the attacker needs to know, to avoid repeating a dead swing against the same target.
