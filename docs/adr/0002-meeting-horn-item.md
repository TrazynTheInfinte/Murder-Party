# Use a Meeting Horn item instead of a placeable button

The original idea was a physical button the host places on the map, wired via redstone to a command block, to call a Meeting. We used a giveable "Meeting Horn" item instead, used by right-clicking from anywhere. A placed button is fragile — it can be broken, griefed, or moved, and the host has to wire the redstone correctly — while the item works from any location with no setup and can't be sabotaged. The cost is that there's no single physical landmark on the map that "is" the meeting-call mechanism.
