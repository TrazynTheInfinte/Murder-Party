# Task Points are fully optional - a Round can start with none placed

Unlike Spawn Points, which require at least one placed before a Round can start, Task Points have no minimum. A Map with zero Task Points placed simply runs a Round with no Tasks at all - no error, no blocked start, no fallback behavior.

We considered requiring at least one Task Point, matching the Spawn Point precedent. We chose to leave it fully optional because Tasks are a balance tool for maps where everyone clustering together has become a problem, not a required feature of every Map - a Map's admin should be free to skip them entirely (especially while only Map 1 exists and is still being built out) without that choice breaking Round start.
