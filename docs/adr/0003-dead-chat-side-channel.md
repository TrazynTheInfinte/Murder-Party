# Dead Chat is a side-channel, not a real mute

Vanilla data packs have no way to intercept or filter chat text per recipient — there is no hook to stop a Spectating participant's ordinary chat message from reaching living players without a server mod/plugin. Rather than pretend to solve this, Spectating participants are given a separate opt-in Dead Chat channel (a `/trigger`-based broadcast visible only to other Spectators) as an alternative to typing in normal chat. Ordinary chat remains technically open to Spectators; this is a known, accepted limitation of staying mod-free, not a bug.
