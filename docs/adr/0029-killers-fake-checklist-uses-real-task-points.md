# The Killer's fake Checklist uses real Task Points, not separate fake ones

The Killer is assigned a Checklist exactly like any Innocent - up to 3 real Task Points, picked the same way - except completing them never reduces the Round Timer. There is no separate pool of decoy-only Task Points built just for the Killer to visit.

We considered a parallel set of Killer-only fake Task Points, so the real ones stay exclusively meaningful. We chose to reuse the real ones instead, because the entire point of giving the Killer a Checklist is letting them plausibly walk toward a Task Point when someone's watching - a decoy-only location the Killer visits but no Innocent ever would is not plausible cover at all, and would double the admin placement work for no gameplay benefit.
