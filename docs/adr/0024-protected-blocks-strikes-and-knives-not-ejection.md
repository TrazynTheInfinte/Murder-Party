# Protected blocks Strikes and knives, not Ejection

The Bodyguard's Protected status only blocks direct single-target elimination attempts — the Killer's Strike, the Vigilante's knife, the Hitman's knife. It does nothing against Ejection: a Protected Participant can still be voted out normally.

We considered making Protected block Ejection too, for a cleaner "fully safe" story. We chose the narrower scope because Ejection is resolved by an entirely separate system (vote tallying at a Meeting, not a Strike/knife resolution), and folding it in would make the Bodyguard meaningfully safer from the group's own votes, not just from the Killer and the one-shot roles - a much bigger power spike than "survive one hit" was meant to be.
